# Bright-TV-CASE-STUDY-

# 📺 BrightTV Viewership Analytics Case Study

## Project Overview

This project was completed as part of the **BrightTV Viewership Analytics Case Study**. The objective was to analyze customer viewing behavior and provide business insights that can help BrightTV increase its subscription base and improve customer engagement.

The analysis focuses on understanding user demographics, viewing patterns, content consumption, and customer behavior through Exploratory Data Analysis (EDA) and interactive Power BI dashboards.

---

# Business Problem

BrightTV's CEO wants to grow the company's subscription base during the current financial year.

As a Data Analyst, my responsibility was to analyze customer viewing data and generate insights that would assist the **Customer Value Management (CVM)** team in making data-driven decisions.

The analysis answers the following business questions:

- What are the major user and viewing trends?
- Which factors influence content consumption?
- Which content should be promoted during low-viewership periods?
- What initiatives can increase BrightTV's subscriber base?

---

# Project Objectives

This project aims to:

- Understand customer demographics
- Analyze viewing behaviour
- Identify peak and low consumption periods
- Discover factors affecting content consumption
- Recommend content strategies
- Suggest initiatives to increase subscribers

---

# Dataset

The dataset contains information about:

- User demographics
- Viewing sessions
- TV channels watched
- Session duration
- Viewing dates and times
- Regions
- Age Groups
- Gender
- Ethnic Groups

Each record represents **one viewing session**.

**Note:** The original timestamps were provided in UTC and converted to South African Standard Time (SAST) as required in the case study.

---

# My Analysis Process

## 1. Data Understanding

I first explored the dataset to understand:

- Available columns
- Data types
- Missing values
- Duplicate records
- Business meaning of each field

---

## 2. Data Cleaning

Before analysis, the data was prepared by:

- Removing duplicate records
- Handling missing values
- Correcting data types
- Standardizing categorical values
- Converting UTC timestamps into South African local time
- Creating additional calculated columns where necessary

Examples include:

- Age Groups
- Duration Buckets
- Day of Week
- Weekend vs Weekday

---

## 3. Exploratory Data Analysis (EDA)

After cleaning the data, I performed Exploratory Data Analysis to identify important trends.

The analysis included:

### User Demographics

- Gender distribution
- Regional distribution
- Age groups
- Ethnic groups

---

### Viewing Behaviour

- Viewing sessions by day
- Weekday vs Weekend consumption
- Session duration
- Popular TV channels
- Long vs Short viewing sessions

---

### Customer Trends

I analyzed relationships between:

- Region vs Gender
- Region vs Age Group
- Age Group vs Ethnicity
- Channel vs Viewing Duration
- Channel vs Weekday/Weekend

---

## 4. Power BI Dashboard

The cleaned dataset was imported into Power BI where interactive dashboards were created to visualize the findings.

The dashboard enables users to explore:

- User demographics
- Regional analysis
- Viewing trends
- Content popularity
- Viewing duration
- Peak viewing periods

Interactive filters allow stakeholders to drill into specific customer segments.

---

# Key Business Insights

The analysis provided insights such as:

- Customer demographic distribution
- Most active regions
- Most popular TV channels
- Peak viewing periods
- Viewing duration patterns
- Differences between weekday and weekend consumption
- User segments with the highest engagement

These insights support strategic decision-making for customer growth.

---

# Recommendations

Based on the analysis, recommendations include:

### Increase Consumption

- Promote popular content during low-viewership days
- Recommend similar content to highly engaged viewers
- Personalize content suggestions by age group and region

### Grow Subscriber Base

- Target marketing campaigns toward underrepresented regions
- Improve customer retention through personalized recommendations
- Focus promotions on high-performing content categories
- Develop campaigns targeting younger audiences with high engagement
